# Follow-up audit remediation

Scope: the five follow-up findings after `b4cf882`, plus the phased performance,
export-size, printer-setting, and independent geometry verification upgrades.

## Phases

1. `96a42d7`: patched development dependencies, explicit app-update acceptance,
   complete print presets, and immutable batch model settings.
2. `e0455cc`: cancellable local workers, stale-result protection, conforming
   coplanar face merging, binary STL, compressed 3MF, and polygon preview caching.
3. This change: nozzle/layer settings, layer-count base presets, printer-aware
   bridge targets, slice-plane regressions, broader stencil decoding, and isolated
   Blender fixture verification.

## Five Findings

| Finding | Remediation | Evidence |

## Upgrade Evidence

- Default URL, raised material mesh: 96,744 -> 16,060 triangles.
- Default URL, through-hole stencil: 105,808 -> 7,288 triangles.
- Default URL STL: 8,670,561-byte ASCII before -> 433,784-byte binary after.
- Default URL compressed 3MF: 152,195 bytes.
- Automated topology checks cover boundary edges, non-manifold edges, winding,
  degeneracy, signed volume, connected stencil geometry, and horizontal sections.
- Stencil raster scan fixtures include text, URL, numeric, Wi-Fi, Japanese, and a
  longer byte payload. These are synthetic raster tests, not camera tests.
- Two-layer bases pass closed-mesh checks at 0.05, 0.1, 0.16, 0.2, 0.24, and
  0.28 mm layer heights. Thin bases still carry a fragility warning.
- Blender 5.2.3 headless imports passed for raised, thin, stencil, single-color,
  and two-color OBJ/STL fixtures. Their dimensions, closed edges, positive volumes,
  and OBJ material regions were checked. Exported 3MF ZIPs, XML meshes, material
  parts, and assembly structure were independently parsed and checked in Blender.
- Local Edge/Playwright checks passed for empty state, text/URL/Wi-Fi/UPI/vCard,
  long-input errors, colors/logo, full preview rotation, three-column actions,
  320/375 px layouts, private POST sharing, updates, and offline generation.
- A fresh-install offline test found a `Vary: Origin` precache mismatch for module
  scripts. Static shell matching now ignores that irrelevant variant; regression
  coverage and fresh offline 3D reload passed after the fix.

## Boundaries

- Bambu Studio slicing and physical prints have not been performed by this run.
- Blender 3MF checks parse its mesh data; they are not a third-party 3MF importer.
- Print times and scannability on actual backing materials are not guaranteed.
- Vite still reports its existing large-entry-chunk warning. Offline worker code
  is bundled inline so it does not require a second uncached worker request.
- Bevels, rounded outer corners, and mounting holes remain separate geometry
  features, outside this follow-up audit scope.
